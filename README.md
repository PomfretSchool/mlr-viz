# MLR visualizations

Prototype data visualizations for Pomfret's Mastery Learning Record: 7 areas × 7 competencies
(3 foundational + 4 advanced). Plain HTML/JS/SVG, no build step, no dependencies.

- `v3/` — castle, garden, compass, dials, seasons, ledger, next moves, review flow, college one-pager, data contract
- `v2/`, `v1/` — earlier rounds

**All student data is synthetic.** Every name, date, and piece of evidence is invented.

Run locally: `python3 -m http.server 8765` in this folder, then open http://127.0.0.1:8765/.
